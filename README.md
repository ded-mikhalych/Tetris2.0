# Tetris RMI

Клиент-серверное приложение на Java RMI, реализующее игру «Тетрис» для одного игрока.

## Что реализовано

- сервер последовательно выдает игроку фигуры из базового набора;
- активная фигура падает вниз по таймеру;
- игрок управляет фигурой до размещения: двигает, поворачивает и сбрасывает вниз;
- размер игрового поля настраивается перед запуском игры;
- очки начисляются с учетом заполненных клеток и пустот;
- результаты игр сохраняются в локальной базе данных SQLite;
- в интерфейсе показываются рекорд и число сыгранных партий;
- игра завершается при заполнении поля или невозможности продолжения;
- графический клиент выполнен в зелено-черном стиле.

Формула очков:

```text
score = occupiedCells * 10 - holes * 2
```

`holes` — пустые клетки, под которыми в том же столбце уже есть размещенные блоки.

## Ограничения поля

- минимальная ширина: `4`
- максимальная ширина: `25`
- минимальная высота: `6`
- максимальная высота: `25`

## Сборка через PowerShell

```powershell
.\scripts\build.ps1
```

Для работы SQLite при запуске через PowerShell или BAT положи JDBC-драйвер `sqlite-jdbc` в папку `lib`.

## Запуск через PowerShell

Сервер:

```powershell
.\scripts\run-server.ps1
```

Клиент:

```powershell
.\scripts\run-client.ps1
```

Подключение к удаленному серверу:

```powershell
.\scripts\run-client.ps1 -ServerHost 127.0.0.1 -Port 2099
```

## Быстрый запуск через BAT

В корне проекта есть готовые bat-файлы:

- `build.bat` — сборка проекта;
- `run-server.bat` — запуск RMI-сервера;
- `run-client-gui.bat` — запуск графического клиента.

Примеры:

```bat
build.bat
run-server.bat
run-client-gui.bat
```

## Возможности GUI-клиента

- главное меню с пунктами `Начать игру` и `Изменить настройки игры`;
- отдельный экран настроек для размеров поля;
- встроенная проверка допустимых размеров прямо в окне настроек;
- управление только с клавиатуры;
- горячие клавиши: `←`, `→`, `↑`, `↓`, `Space`, `Enter`, `Esc`;
- игровое поле, счет, число пустот и индикатор завершения игры.

## Сборка через Maven

```bash
mvn clean package
```

## Запуск через Maven

Сервер:

```bash
mvn exec:java "-Dexec.mainClass=ru.danil.tetris.rmi.server.ServerMain"
```

Клиент:

```bash
mvn exec:java "-Dexec.mainClass=ru.danil.tetris.rmi.client.TetrisSwingClient"
```
